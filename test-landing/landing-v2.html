Sıkça Sorulan Sorular

Merak ettiğiniz her şey

Qwen Code, komut satırı üzerinden çalışan bir AI asistanıdır. Projenizin dosyalarını analiz eder, kod önerileri sunar ve geliştirme sürecinizi otomatikleştirir. Node.js tabanlıdır ve TypeScript projeleriyle tam entegre çalışır.

Qwen Code, TypeScript, JavaScript, Python, Java, C++, Go, Rust ve daha birçok modern programlama dilini destekler. Özellikle web geliştirme ve backend projeleri için optimize edilmiştir.

Evet, Qwen Code verilerinizi yerel olarak işler ve hiçbir kod verinizi sunucularımıza göndermez. Tüm analizler kendi makinenizde gerçekleşir ve end-to-end şifreleme ile korunur.

Qwen Code'u npm üzerinden tek komutla kurabilirsiniz: npm install -g qwen-code. Node.js 20+ sürümü gerektirir. Kurulumdan sonra hemen kullanmaya başlayabilirsiniz.

Evet, Qwen Code VS Code, IntelliJ, WebStorm ve diğer major IDE'ler ile entegre olabilir. Terminal üzerinden çalıştığı için herhangi bir IDE'de sorunsuz kullanabilirsiniz.
